## 1. 治験の概要

### 1.1 治験の標題

中等症から重症の関節リウマチ患者を対象としたXYZ-501の有効性及び安全性を
検討する第III相無作為化実薬対照比較試験

### 1.2 開発の相

第III相

### 1.3 目的

1. 主要目的: 投与24週後のACR20達成率により有効性を評価する
2. 副次目的: 長期投与時の安全性を評価する

### 1.4 デザイン

無作為化、非盲検、実薬対照、並行群間比較

### 1.5 目標症例数

全体240例

## 2. 被験者の選択

### 2.1 選択基準

1. 同意取得時の年齢が**18歳以上**の者
2. 関節リウマチと診断され、罹病期間が6か月以上の者
3. メトトレキサートによる治療を12週間以上継続しても効果不十分な者
4. 文書による同意が得られた者

### 2.2 除外基準

1. **活動性の感染症を有する者**
2. **結核の既往を有する者、又はスクリーニング検査で結核感染が疑われる者**
3. B型肝炎ウイルス又はC型肝炎ウイルスのキャリアである者
4. 悪性腫瘍の既往を有する者（治癒後5年以上経過した者を除く）
5. 妊娠中、授乳中又は妊娠を希望する女性
6. その他、治験責任医師が不適当と判断した者

### 2.3 スクリーニング時の必須検査

以下は本治験の安全性確保上、**すべての被験者に対して必須**である。

1. 胸部X線検査
2. インターフェロンγ遊離試験（IGRA）
3. HBs抗原、HBs抗体、HBc抗体、HCV抗体

## 3. 治験薬

### 3.1 治験薬の概要

| 項目 | 内容 |
|---|---|
| 治験薬 | XYZ-501注 100mg／1mLバイアル |
| 対照薬 | 標準治療薬（既承認の生物学的製剤） |
| 剤形 | 注射剤（凍結乾燥製剤ではなく液剤） |
| 包装 | 1バイアル／箱 |

### 3.2 用法及び用量

1. XYZ-501群: **2週間に1回**、100mgを皮下投与する。
2. 対照群: 添付文書に従った用法・用量で投与する。
3. 投与期間は24週間とする。

### 3.3 投与方法

1. 治験薬の投与は**実施医療機関において医療従事者が行う**。
   被験者による自己注射は本治験では認めない。
2. 投与部位は腹部、大腿部又は上腕部とし、毎回部位を変更する。
3. 投与後**30分間**は院内で被験者を観察する。

### 3.4 保管条件

**冷所（2℃〜8℃）**で保管する。**凍結させてはならない。**
遮光して保管すること。詳細は治験薬取扱説明書を参照。

### 4.3 関節評価

1. 関節評価は**同一の評価者**が実施することを原則とする。
2. 評価者は治験依頼者が実施するトレーニングを受講した者に限る。
3. 評価者は投与を行う者と別の者とすることが望ましい。

## 5. 有害事象

### 5.1 重篤な有害事象の報告

1. 治験責任医師は、重篤な有害事象を知った場合、
   **24時間以内**に治験依頼者へ第一報を報告する。
2. 詳細報告は第一報から**3営業日以内**に提出する。

### 5.2 特に注意すべき有害事象

本治験薬は免疫抑制作用を有するため、以下に特に注意すること。

1. **重篤な感染症**（肺炎、敗血症、日和見感染）
2. **結核の再燃**
3. B型肝炎ウイルスの再活性化
4. 注射部位反応
5. アナフィラキシー等の過敏症反応

### 5.3 感染症発現時の対応

1. 感染症を疑う症状（発熱、咳嗽等）を認めた場合、速やかに評価を行う。
2. **重篤な感染症と判断された場合、治験薬の投与を中断する。**
3. 投与再開の可否は、感染症の回復を確認したうえで治験責任医師が判断する。

## 6. 中止基準

以下に該当する場合、当該被験者の治験を中止する。

1. 同意撤回の申し出があった場合
2. 重篤な感染症が発現し、投与継続が不適当と判断される場合
3. 結核の発症が確認された場合
4. 妊娠が判明した場合
5. アナフィラキシーが発現した場合
6. その他、治験責任医師が継続を不適当と判断した場合
