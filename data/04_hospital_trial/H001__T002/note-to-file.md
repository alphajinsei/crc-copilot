## NTF-001

| 項目 | 内容 |
|---|---|
| 作成日 | 2026年4月8日 |
| 件名 | IGRA検体の採血曜日に関する運用確認 |
| 作成者 | CRC |

### 経緯

2026年4月7日（火）、被験者002-004のスクリーニング来院を予定していたが、
被験者の都合により**金曜日への変更**の申し出があった。

ラボマニュアル第3.4項において、
IGRA検体は「金曜日及び休前日の採血は原則として実施しない」と定められている。

### 対応

1. CRCが担当モニターへ照会した。
2. モニターより、以下の回答を得た。
   - IGRA検体は採血後16時間以内に中央検査機関へ到着する必要がある
   - 金曜日採血の場合、集荷が翌週月曜となり条件を満たさない
   - **スクリーニング来院を金曜日に設定することは避けること**
3. 被験者と再調整し、翌週火曜日に来院日を設定した。

### 決定した運用

1. **スクリーニング来院は月曜日から木曜日に設定する。**
2. 予約時にCRCが曜日を確認する。
3. 祝日の前日も同様に避ける。
4. 上記をSpecific SOPの運用として周知した（第6.3項に反映済み）。

### 補足

スクリーニング以外の来院（IGRA採血を伴わない来院）については
曜日の制約はない。

## NTF-002

| 項目 | 内容 |
|---|---|
| 作成日 | 2026年5月21日 |
| 件名 | 治験薬冷蔵庫の一時的な温度低下について |
| 作成者 | 薬剤部 治験薬管理担当薬剤師 |

### 経緯

2026年5月20日、治験薬専用冷蔵庫の温度記録を確認したところ、
5月19日の夜間に**庫内温度が1.2℃まで低下**していたことが判明した。

8℃を超える上昇はなく、**0℃以下には至っていない**。
2℃を下回っていた時間は約40分であった。

### 対応

1. 該当する治験薬（未使用6バイアル）を直ちに隔離した。
2. 目視確認を行い、**凍結の形跡、混濁、変色、不溶性異物は認められなかった**。
3. 同日、担当モニターへ連絡し、温度記録の写しを送付した。

### 治験依頼者の判断

2026年5月22日、治験依頼者より書面にて回答を受領した。

- 0℃以下には達しておらず、凍結の可能性は低い
- 目視で異常が認められない
- 以上より**使用可**と判断する

### 結論

隔離を解除した。

### 原因及び再発防止

1. 冷蔵庫の設定温度を確認したところ、**3℃に設定されていた**ことが判明した。
   治験薬取扱説明書は5℃前後を推奨している。
2. 設定温度を**5℃に変更**した。
3. 設定温度の変更は治験薬管理者の承認を要することとし、
   変更時は記録を残す運用とした。
4. 変更後1週間の温度推移を確認し、2℃〜8℃の範囲内で
   安定していることを確認した（記録添付）。

### 教訓

温度逸脱は上限側だけでなく**下限側にも注意**を要する。
本治験薬は凍結により使用不可となるため、特に重要である。
本件を薬剤部内で共有した。

## NTF-003

| 項目 | 内容 |
|---|---|
| 作成日 | 2026年6月25日 |
| 件名 | 関節評価者の不在に伴う来院日変更について |
| 作成者 | CRC |

### 経緯

2026年6月24日に予定していた被験者002-002のVisit 6において、
専任の関節評価者が**急病により不在**となった。

治験実施計画書第4.3項は、関節評価を同一評価者が実施することを原則としている。

### 判断及び対応

1. CRCが治験責任医師に報告した。
2. 治験責任医師が担当モニターへ照会した。
3. モニターより、以下の見解を得た。
   - 関節評価は評価者間のばらつきを避けるため同一評価者が望ましい
   - ただし**Visit 6は許容範囲が±3日**であり、期間内であれば来院日の変更が可能
   - 評価者を交代させるより、来院日を変更することが望ましい
4. 被験者と調整し、**6月26日（許容範囲内）**に来院日を変更した。
5. 変更後の来院において、専任評価者が関節評価を実施した。

### 結果

許容範囲内の変更であり、**逸脱には該当しない**。

### 再発防止

1. 評価者の不在が事前にわかる場合（学会出張、休暇等）は、
   CRCが月初に予定を確認し、来院日設定時に考慮する運用とした。
2. 急病等の予測できない不在については、
   **許容範囲内での来院日変更を第一選択**とすることを確認した。
3. 許容範囲内で調整できない場合の対応（代替評価者の可否）については、
   事前に治験依頼者と協議しておくこととし、次回モニタリング時に相談する。

## NTF-004

| 項目 | 内容 |
|---|---|
| 作成日 | 2026年7月10日 |
| 件名 | 被験者002-005の投与後観察時間の短縮について |
| 作成者 | CRC |

### 経緯

2026年7月9日、被験者002-005のVisit 7において治験薬を投与した。

治験実施計画書第3.3項及び本院Specific SOP第3.3項は、
投与後**30分間**の院内観察を定めている。

被験者は投与後**22分**の時点で、家族の迎えの都合により
帰宅を強く希望した。

### 対応

1. 看護師がCRCに連絡した。
2. CRCが治験分担医師に報告した。
3. 治験分担医師が被験者を診察し、以下を確認した。
   - バイタルサインに異常なし
   - 注射部位反応なし
   - 自覚症状なし
4. 治験分担医師は、被験者の強い希望を踏まえ、
   **観察を22分で終了することを許可**した。
5. 被験者に対し、帰宅後に体調変化があった場合の連絡先を改めて説明し、
   緊急連絡先カードの携帯を確認した。

### 逸脱の判断

治験実施計画書に定める30分の観察時間を満たしていないため、
**治験実施計画書からの逸脱**に該当する。

1. 発生当日にCRCが担当モニターへ電話連絡した。
2. 治験責任医師が逸脱報告書を作成し、治験事務局へ提出した。
3. 治験依頼者へ逸脱を報告した。

### 治験依頼者の見解

- 医師の診察により安全性が確認されていること
- 観察時間の不足が8分であること
- 帰宅後に有害事象の発現がなかったこと

以上より、**被験者の安全性への影響はなく、
データの取扱いにも影響しない**との見解を得た。
被験者の治験継続は可能である。

### 再発防止

1. 投与日の来院前連絡において、
   **投与後30分の観察が必要であること**を改めて説明する。
2. 来院予定時刻の設定において、被験者の帰宅時間の都合を事前に確認する。
3. 送迎を伴う被験者については、
   **迎えの時刻を投与予定時刻＋60分以降**に設定するよう依頼する。
4. 上記をCRC間で共有し、来院前連絡のチェックリストに追加した。
