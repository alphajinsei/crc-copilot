## NTF-001

| 項目 | 内容 |
|---|---|
| 作成日 | 2026年4月17日 |
| 件名 | 検査部における絶食時間の基準の相違について |
| 作成者 | CRC（院内） |

### 経緯

2026年4月16日、被験者003-002のスクリーニング来院において、
検査部の担当技師より
「絶食時間は8時間以上で足りるのではないか」との問い合わせがあった。

本院検査部の治験検体取扱手順書（MINATO-LAB-005）第3.4項は
空腹時採血を**8時間以上の絶食**と定めている。

一方、ABC-201試験の治験実施計画書第4.3項及びラボマニュアル第3.3項は
**10時間以上の絶食**を求めている。

### 判断

1. CRCが担当モニターへ照会した。
2. モニターより、**本治験では10時間以上の絶食が必須**であるとの回答を得た。
3. ラボマニュアル第1章に「実施医療機関の検査部門手順書と本マニュアルの
   記載が異なる場合は本マニュアルを優先する」との定めがあることを確認した。
4. 検査部手順書第2章にも「個別の治験のラボマニュアルに異なる定めがある場合は
   ラボマニュアルを優先する」との記載があり、両文書の定めは整合している。

### 対応

1. 当該被験者は前日20時に夕食を終えており、
   来院時の絶食時間は**12時間30分**であった。条件を満たすため採血を実施した。
2. 検査部に対し、本治験では10時間以上の絶食が必要である旨を文書で周知した。
3. 治験専用採血ブースに、本治験の絶食条件を記載した掲示を行った。
4. Specific SOP第6.2項に本件を明記した。

### 教訓

院内手順書と治験固有文書で基準が異なる場合がある。
**科学的品質に関わる事項は治験固有文書が優先される**ことを、
関係部署に改めて周知した。

## NTF-002

| 項目 | 内容 |
|---|---|
| 作成日 | 2026年5月8日 |
| 件名 | 重篤な有害事象の報告時限に関する運用の確認 |
| 作成者 | 臨床研究支援センター |

### 経緯

本院の治験標準業務手順書第17条は、重篤な有害事象の報告について
**「直ちに（遅くとも12時間以内に）」**と定めている。

一方、ABC-201試験の治験実施計画書第5.3項は
**24時間以内**の第一報を求めている。

両者の期限が異なるため、本治験における運用を明確化する必要が生じた。

### 検討

1. 治験実施計画書の24時間以内は、治験依頼者が求める最低限の期限である。
2. 本院の12時間以内は、これより厳しい院内基準である。
3. **より厳しい基準を適用しても治験実施計画書に違反しない。**

### 決定

1. 本治験における重篤な有害事象の第一報は、
   **本院基準である12時間以内**とする。
2. 夜間・休日であっても臨床研究支援センターの緊急連絡先へ連絡する。
   翌営業日への繰り延べは行わない。
3. 治験依頼者への報告と院内報告を並行して行う。

### 周知

1. 治験責任医師及び治験分担医師へ文書で周知した。
2. Specific SOP第7.1項に明記した。
3. 緊急連絡先の一覧を診療科及び病棟に掲示した。

### 担当モニターの確認

2026年5月11日、担当モニターへ本運用を説明し、
**院内基準を適用することに問題はない**との確認を得た。

## NTF-003

| 項目 | 内容 |
|---|---|
| 作成日 | 2026年6月2日 |
| 件名 | 治験依頼者提供ワークシートの様式変更に伴う承認手続について |
| 作成者 | CRC（院内） |

### 経緯

2026年5月28日、治験依頼者よりワークシートの改訂版（第3版）が交付された。
主な変更点は、有害事象記録欄の追加である。

本院の治験標準業務手順書第14条は、
**ワークシートは臨床研究支援センターが様式を承認したものに限り
使用できる**と定めている。治験依頼者提供の様式も承認の対象である。

### 対応

1. CRCが改訂版ワークシートを臨床研究支援センターへ提出した。
2. 臨床研究支援センターが内容を確認し、2026年6月1日に承認した。
   - 確認内容: 被験者氏名欄がないこと、記録項目が原資料要件を満たすこと
3. 承認後、旧版（第2版）の使用を停止した。
4. 使用済みの旧版ワークシートは原資料としてそのまま保管する。

### 切り替えの運用

1. 切り替え日を**2026年6月2日**とした。
2. 6月1日までの来院は第2版、6月2日以降の来院は第3版を使用する。
3. 切り替え日をCRC間で共有し、旧版の様式は保管庫から撤去した。

### 留意事項

**治験依頼者から交付された様式であっても、
本院では臨床研究支援センターの承認が必要**である。
今後の改訂時も同様の手続を行う。
承認手続には数営業日を要するため、
改訂版の交付を受けた時点で速やかに提出すること。

## NTF-004

| 項目 | 内容 |
|---|---|
| 作成日 | 2026年7月6日 |
| 件名 | モニタリング直接閲覧の予約期限に関する調整 |
| 作成者 | CRC（院内） |

### 経緯

2026年7月3日、担当モニターより
**7月8日の直接閲覧**の希望連絡があった。

本院の治験標準業務手順書第20条は、
直接閲覧の予約を**7営業日前まで**に申し込むことと定めている。
7月3日の申込は、7月8日の閲覧に対して**3営業日前**にあたり、
期限を満たさない。

### 対応

1. CRCが臨床研究支援センターへ相談した。
2. 専用閲覧室の空き状況を確認したところ、
   7月8日は既に他の治験のモニタリングで予約されていた。
3. モニターへ状況を説明し、日程を再調整した。
4. **7月15日（申込から8営業日後）**に閲覧日を設定した。

### 決定した運用

1. CRCは、モニターに対して**7営業日前の予約期限**を
   治験開始時に案内済みであったが、改めて文書で共有した。
2. 定期モニタリング（8週に1回）については、
   **年間の予定日をあらかじめ仮予約**しておく運用に変更した。
3. 仮予約は臨床研究支援センターの了承を得て、
   2026年度分の日程を確保した。
4. 日程変更が必要な場合は、変更後の日程についても
   7営業日前までに申し込む。

### 補足

本院は複数の治験を並行して実施しており、専用閲覧室の稼働率が高い。
予約期限は運用上必要なものであり、短縮は困難である旨、
臨床研究支援センターより説明があった。
