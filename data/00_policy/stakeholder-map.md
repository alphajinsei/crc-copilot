# ステークホルダー対応指針

> **この文書の位置づけ**
>
> CRCを取り巻く関係者それぞれについて、役割・権限・連絡時の留意点を定める。
> [crc-principles.md](crc-principles.md) と同じく**行動原則**であり、
> 出典として引用してはならない。
>
> 本文書はPoC用のサンプルである。実運用では、所属組織の体制に合わせて精査すること。

- 文書番号: POLICY-002
- 版数: 第1版
- 最終改訂日: 2026年8月10日

## 第1章 ステークホルダー一覧

| 識別子 | 相手 | 持つ権限 | CRCとの関係 |
|---|---|---|---|
| `doctor` | 治験責任医師・治験分担医師 | 医学的判断のすべて | 指導を受ける立場 |
| `supervisor` | CRCリーダー・SMO管理者・治験事務局 | 業務品質・体制・施設運用 | 報告する立場 |
| `patient` | 被験者 | 参加・撤回の自由 | 保護し支援する対象 |
| `sponsor` | 治験依頼者（担当モニター） | 治験全体の管理・治験薬の取扱い判断 | 対等な連携相手 |
| `internal` | CRC自身・施設内スタッフ | — | 記録作成、他職種との調整 |

## 第2章 医師（doctor）

### 2.1 権限

**医学的判断のすべてを担う。** CRCが代行してはならない。

- 有害事象の重篤性・因果関係の判断
- 治験薬の投与継続・中止・用法変更の判断
- 被験者の治験継続可否の判断
- 選択・除外基準への適合性の判断
- 同意説明と同意の取得

### 2.2 連絡の原則

**医学的判断を要する事象は、原則として最初に医師へ。**
医師の判断が出ないと、他の関係者に伝えるべき内容が確定しないため。

### 2.3 連絡時の留意点

- **事実と推測を分けて伝える。** 「〜のようです」と「〜です」を混同しない
- 判断に必要な情報を揃えてから連絡する。ただし緊急時は揃うのを待たない
- 何を判断してほしいのかを明示する。「報告です」なのか「判断を仰ぎたい」のかを最初に言う
- 医師は多忙である。結論から、簡潔に
- 口頭で指示を受けた場合、内容を復唱して確認し、記録する

### 2.4 連絡がつかない場合

1. 治験分担医師への連絡を試みる
2. それでもつかない場合、上司へ先に一報し、医師への連絡を継続する
3. 緊急性がある場合は当直医・救急体制に従う
4. 連絡を試みた時刻と手段を記録する

## 第3章 上司（supervisor）

### 3.1 役割

- CRC業務の品質と体制に責任を負う
- 複数の治験・複数の施設を横断して状況を把握している
- 組織としての対応（人員配置、治験依頼者との交渉、再発防止）を判断する

### 3.2 連絡の原則

**医師への一報の後、速やかに。**
「解決してから報告する」のではなく、**対応中の段階で共有する。**

早期に共有する理由:
- 同種の事象が他施設・他治験で起きている可能性がある
- 組織として治験依頼者と交渉すべき場面がある
- CRC個人で抱え込むと判断を誤りやすい

### 3.3 報告すべき事象

判断に迷う場合は報告する（原則4「迷ったら報告する」）。

典型的に報告すべきもの:
- 逸脱またはその可能性がある事象
- 有害事象（重篤性を問わない）
- 被験者からの苦情・不満・撤回の申し出
- 治験依頼者との認識の相違
- 施設側の体制・手順に問題があると感じた事象
- 自分の判断に確信が持てない事象

### 3.4 連絡時の留意点

- 現在の状況、すでに取った対応、これから取る予定の対応を整理して伝える
- 判断を仰ぎたいのか、共有のみなのかを明示する
- 悪い情報ほど早く伝える

## 第4章 被験者（patient）

### 4.1 位置づけ

**他のステークホルダーとは性質が根本的に異なる。**
被験者は業務上の関係者ではなく、**保護されるべき対象**である。

被験者は以下の権利を持つ。

- いつでも理由を告げずに参加をやめる権利
- 治験に関する情報を知る権利
- 質問し、十分に考慮する時間を得る権利
- 個人情報が保護される権利

### 4.2 連絡の原則

**医師の判断が出てから連絡する。**

先走って連絡してはならない理由:
- 医師の判断が異なった場合、訂正が必要になり不信を招く
- 医学的な見通しをCRCが述べることは越権であり、危険でもある
- 被験者が誤った行動（過量服用など）を取るおそれがある

**例外**: 事実確認そのものが必要な場合（来院しなかった、連絡が取れないなど）は、
被験者への確認が先行する。この場合も**医学的な見通しは述べない。**

### 4.3 連絡時の留意点

#### 責めない

被験者に落ち度がある場合（飲み忘れ、来院忘れ、併用薬の申告漏れ）でも、
責める姿勢をとらない。

責めると次から申告しなくなり、**かえって安全性とデータ品質が損なわれる。**
申告してくれたことに感謝し、事実を確認することに集中する。

#### 安易な保証をしない

- 「大丈夫です」「問題ありません」と断定しない
- 医師の判断が出ていない段階では「確認して折り返します」と伝える
- 不安を軽減する配慮はするが、根拠のない安心を与えない

#### 分かる言葉で

- 専門用語を避ける。「有害事象」ではなく「体調の変化」
- 一度に多くを伝えない。重要なことを絞る
- 理解を確認する。「ご不明な点はありますか」で終わらせず、要点を復唱してもらう

#### 記録する

説明した内容、日時、被験者の反応を記録する。
電話連絡も記録の対象である。

### 4.4 被験者から撤回の申し出があった場合

- **引き留めない。** 撤回は被験者の権利である
- 理由を尋ねてもよいが、答えを強要しない
- 速やかに医師へ報告する
- 撤回後の検査・観察について、医師の指示を仰ぐ

## 第5章 治験依頼者（sponsor）

### 5.1 役割と権限

- 治験全体の管理責任を負う
- 治験薬の取扱いに関する判断（使用可否、返却、廃棄）
- 逸脱の評価とデータの取扱いの判断
- 治験実施計画書の解釈に関する最終的な見解

### 5.2 連絡の原則

**施設内の事実確認が済んでから。**

理由:
- 不確かな情報を伝えると、後の訂正で混乱を招く
- 治験依頼者は複数施設を管理しており、誤情報の影響が広がる

**例外**: 報告期限が定められている事象（重篤な有害事象など）は、
期限が順序に優先する。事実確認と並行して第一報を入れる。

### 5.3 連絡時の留意点

- 事実を客観的に伝える。施設側の解釈や言い訳を混ぜない
- 判断を仰ぐ場合は、何を判断してほしいのかを明示する
- **口頭の回答だけで運用を変えない。** 重要な判断は書面で受け取る
- 記録（温度記録、日誌、検査値）を添えると判断が早い
- 回答を待つ間に何をすべきか（隔離、使用停止など）を確認する

### 5.4 治験依頼者の判断を待つ間

判断が出るまで、対象を**現状のまま保全する。**

- 治験薬は隔離し、使用・交付しない
- 検体は現在の条件で保管を継続する
- 記録は改変しない

「たぶん問題ないから進めておく」は最も避けるべき行動である。

## 第6章 施設内の他職種（internal）

### 6.1 薬剤師

- 治験薬の管理・調剤・交付・服薬指導を担当
- 治験薬管理者として、保管条件と記録に責任を負う
- 治験薬に関する事象では、CRCより先に薬剤師が動くべき場面が多い
  （隔離、温度記録の確認など）

### 6.2 看護師

- バイタルサイン測定、採血・処置、治験薬投与の介助
- 有害事象の第一発見者となることが多い
- 治験の内容を十分に把握していない場合があるため、要点を絞って伝える

### 6.3 臨床検査技師

- 検体の採取・処理・保管・搬送
- ラボマニュアルの条件（遠心条件、保管温度、搬送期限）を守る役割
- 院内手順とラボマニュアルが異なる場合、**ラボマニュアルが優先される**旨を
  事前に共有しておく

### 6.4 治験事務局

- 治験審査委員会の運営、契約、文書管理
- 施設の運用に関する判断の窓口
- 逸脱報告、モニタリング日程調整の経由地となることが多い

### 6.5 連絡時の留意点

他職種は治験を専門としていない場合がある。

- 治験特有の要求（許容範囲、記録の厳密さ）の**理由**を添えて伝える
- 「決まりだから」ではなく「データの信頼性に関わるから」と説明する
- 手順の変更は事前に、口頭ではなく文書で共有する

## 第7章 連絡順序の判断表

状況に応じた典型的な順序。**個別の状況と資料の定めが優先される。**

| 状況 | 順序 | 備考 |
|---|---|---|
| 医学的判断が必要（服薬・併用薬・症状） | 医師 → 上司 → 被験者 → 依頼者 | 基本形 |
| 重篤な有害事象 | 医師 ＋ 依頼者（並行） → 上司 | 報告期限が優先 |
| 治験薬の取扱い（温度逸脱・破損） | 薬剤師 → 依頼者 → 医師 → 上司 | 判断権限が依頼者にある |
| 検体の取扱いミス | 検査部門 → 依頼者／中央検査機関 → 医師 → 上司 | 検体の保全が先 |
| 被験者の来院なし・連絡なし | 被験者 → 医師 → 上司 → 依頼者 | 事実確認が先行 |
| 被験者からの苦情 | 上司 → 医師 → 依頼者 | 組織として対応 |
| 同意撤回の申し出 | 医師 → 上司 → 依頼者 | 引き留めない |
| 手順に関する疑義 | 上司または依頼者 | 緊急性が低ければ確認優先 |
| 記録の不備を発見 | 上司 → 医師 → 依頼者 | 遡及記載をしない |

## 第8章 アクション提示の書き方

本アプリがネクストアクションを提示する際の指針。

### 8.1 具体的に書く

- ✗ 「医師に報告する」
- ✓ 「治験責任医師に、飲み忘れた日数（3日分）と残薬数を報告し、
  服薬継続の可否と用法の調整について判断を仰ぐ」

**誰に、何を伝え、何を得るのか**を書く。

### 8.2 順序の理由を添える

なぜその順序なのかを示す。理由が分かればCRCは状況に応じて調整できる。

### 8.3 タイミングを示す

「本日中」「医師の判断確定後」「次回来院時」など。
依存関係がある場合は明示する。

### 8.4 CRCの権限外のことを指示しない

- ✗ 「服薬を中止するよう被験者に伝える」（医学的判断をCRCがしている）
- ✓ 「医師の判断を確認し、その指示を被験者に伝える」

### 8.5 資料に定めがある場合は、それを優先する

アクションを提示する前に、該当する手順が資料に定められていないか確認する。
定めがあればそれに従い、出典を示す。
定めがない部分についてのみ、原則に基づく提案であることを明示して述べる。
